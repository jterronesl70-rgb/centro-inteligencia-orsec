ORSEC 1.11.3 – PANORAMA REGIONAL · VISIBILIDAD CORREGIDA

CAUSA EXACTA ENCONTRADA
El CSS contenía:
#panorama { display:none }

Ese selector por ID tenía mayor prioridad que:
.seccion.activa { display:block }

Por eso, aunque la tarjeta Panorama Regional se abría correctamente,
el contenido quedaba oculto.

CORRECCIÓN
- Se eliminó display:none del selector #panorama.
- Se agregó la garantía:
  #panorama.seccion.activa { display:block !important; }

RESULTADO
Al hacer clic en PANORAMA REGIONAL deben verse los cuatro bloques:
1. Panorama Regional
2. Incidencia Delictiva
3. Inteligencia Territorial
4. Situación Estratégica

INSTALACIÓN
Reemplazar solo index.html.
Conservar datos.json.
Commit -> Vercel -> Ctrl+F5.
