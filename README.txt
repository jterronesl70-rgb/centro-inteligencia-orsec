ORSEC - CEREBRO ACTIVO
======================

ESTA ENTREGA ESTA PENSADA PARA NO COMPLICAR LA ESTRUCTURA DE TU GITHUB.

SOLO NECESITAS DOS ARCHIVOS EN LA RAIZ DEL REPOSITORIO:
1) index.html
2) datos.json

PASOS SEGUROS:
1. Antes de reemplazar nada, descarga una copia del index.html actual si deseas respaldo.
2. En GitHub, reemplaza index.html por el de este paquete.
3. Sube datos.json a la MISMA ubicación que index.html (raíz del repositorio).
4. Haz Commit changes.
5. Espera a que Vercel publique el nuevo commit.
6. Recarga la web con Ctrl+F5.

NO BORRES los otros archivos (app.js, reloj.js, style.css, etc.). Pueden quedarse donde están; esta versión no depende de ellos.

FUNCIONES ACTIVAS:
- Incidencia Delictiva con filtros reales.
- Boletín automático.
- Alertas comparativas 2025-2026.
- Inteligencia Territorial con ranking de las 12 provincias.
- Los datos provienen del Excel institucional proporcionado para ORSEC.

IMPORTANTE SOBRE 2026:
- Acumulados provinciales oficiales disponibles: enero-mayo, enero-junio, enero-julio y enero-22 de agosto.
- Cuadros mensuales provinciales oficiales disponibles en este motor: junio, julio y agosto al 22.
- Los acumulados 2025 usados para comparar se calculan sumando las hojas mensuales 2025 del Excel.
